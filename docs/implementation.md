# 第一阶段实现记录

> 后续实现与当前验收状态见 [2026-11-05 开发状态](./development-status.md)。以下为第一阶段历史记录，备份、Mac 引用、歌词与增益等边界已发生变化。

更新：2026-11-04。已按确认的「日落唱片」方向建立原生 SwiftUI 界面。

## 运行

用 Xcode 打开 `Zuneyra.xcodeproj`，选择 `Zuneyra` scheme。选择 My Mac 运行原生 macOS 应用，或选择 iPhone／iPad 模拟器运行 iOS 应用。最低构建目标为 iOS 17、macOS 14；实际最低系统兼容性仍需对应设备验证。真机运行需在 Xcode 配置有效签名。

首次打开为空音乐库。点击“导入音乐”，选择音频文件或文件夹。成功导入后可按专辑、歌曲、艺术家浏览，搜索标题／专辑／艺术家，收藏歌曲。进入专辑后可播放全部或选择单曲；底部播放器支持暂停、上一首、下一首，点击歌曲信息打开完整播放器并拖动进度；队列入口支持编辑当前播放上下文、切换随机与循环模式。

两端当前均使用**复制导入**：原文件不移动、不改写。可以删除原位置文件后继续播放应用中的副本。音乐文件保存在应用 Application Support/Zuneyra/Media，音乐库为同目录的 SQLite 数据库。卸载应用前应自行保存原音乐文件；本阶段尚未提供完整备份导出。

## 实现与边界

- 一个 multiplatform app target 编译为原生 iOS 与 macOS 应用，平台条件编译隔离音频会话和桌面布局；应用级 PlayerStore 共享同一进程的播放器。
- MusicRepository actor 负责文件复制、流式 SHA-256 去重、AVFoundation 元数据提取、SQLite 持久化。单文件失败不撤销成功文件，导入结束展示失败明细；取消保留已完成部分。
- 临时文件先进入 Staging，成功解析后移入 Media 并写数据库，失败清理对应副本。重启清理未完成的 Staging 文件。进程在最终移动与数据库提交之间被杀死可能留下未引用的文件；完整导入日志和孤儿文件回收仍属于后续可靠性工作。
- SQLite schema v2 以独立 Track ID 和唯一内容哈希保存可编码元数据，增加歌单与有序成员关系，并通过事务从 v1 升级；艺术家／专辑关系仍待后续规范化。不会用文件名判断内容重复。
- 基础播放采用 AVPlayer，使用实际媒体时间更新进度，监听失败、自然结束和播放状态；支持系统媒体命令、iOS 后台音频模式、耳机断开暂停与来电中断策略。
- 使用 UserDefaults 保存独立队列条目、当前条目、随机／循环模式和位置，定期与暂停／切歌时检查点保存；重启恢复为暂停，不自动发声。
- 封面读取内嵌图片，按 600 像素生成显示缩略图；缺失封面显示日落风格的本地占位图，不产生网络请求。

本阶段以真实本地文件为内容，没有内置示例音乐。格式筛选包含 MP3、AAC/M4A、ALAC、FLAC、WAV、AIFF，但每个文件仍须通过系统解码检查。本阶段测试音频样本为合成 PCM WAV，其他编码、复杂标签和最低系统仍需扩展真机矩阵；不能据此宣称所有编码变体已验证。

## 后续范围

Mac 文件夹引用与授权续期、独立导入任务日志、无缝播放、AVAudioEngine 后端验证、歌词、ReplayGain、备份迁移不属于本阶段已完成能力。AVPlayer 是基础播放切片的明确选择；专业音频后端按设计文档 M0/M3 另行验证。

后台、锁屏、蓝牙和来电行为已接入系统 API，仍需要物理 iPhone 的长时间播放与路由矩阵验收。模拟器或构建通过不能替代这些验证。

已启用 iOS Finder／“文件”App 对 Documents 的访问。应用加载和回到前台时自动检查新音乐，也可通过 iOS 导入菜单中的“导入电脑传入的音乐”手动触发。已处理记录保存在私有目录，原传入文件保留，继续沿用复制入库和内容去重。完整使用步骤见 [Finder 文件共享导入](./finder-import.md)。

本次 iOS 模拟器的 9 项测试通过，包括最终安装包配置、自动扫描刷新、跨启动去重记录、修复后重试与变化文件延后处理。实际 Mac Finder 到物理 iPhone 的传输仍需真机验收。

## 音乐库管理更新

已实现歌曲多选与删除、存储统计、已入库传入文件核对清理、封面缓存重建，以及最近 100 次导入结果与失败重试。详见 [音乐库管理](./library-management.md)。删除会清理播放状态与所选队列项，并使用暂存清单和数据库事务支持中断恢复。

## 播放队列更新

已实现独立条目的队列编辑、下一首与追加、待播拖动排序和移除、清空待播、随机／列表循环／单曲循环，以及 v2 队列快照。重启恢复精确顺序与进度并保持暂停，兼容旧版会话；切歌时跳过丢失文件并限制重试次数。使用规则和边界见 [播放队列与播放模式](./playback-queue.md)。

## 本地歌单更新

两端新增歌单入口，支持创建／重命名／删除、自动封面、数量与总时长、歌曲／多选／专辑添加、详情多选添加、拖动与菜单排序、移除、顺序和随机播放、插入／追加队列，以及本地重启恢复。删除歌单保留音乐库与播放队列；删除音乐库歌曲会同步清理歌单引用。详见 [本地歌单](./playlists.md)。

本次在连接的 iPhone 15 上使用隔离测试音完成人工配合验收，记录见 [iPhone 真机播放验收](./device-playback-validation.md)。
