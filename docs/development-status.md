# 开发状态与本轮验收

更新：2026-11-05。此文档优先于较早实现记录中的“尚未实现”描述。当前版本范围以本页及范围决策为准；历史测试结果仍按实际证据记录。

## 已接入的能力

- **导入中断恢复**：每个文件复制前持久化 ImportJobs 清单。启动时核对已提交曲目，只清除清单拥有的未提交文件；保留已入库文件和无清单的未知文件。取消保留成功曲目。中断文件需要重新导入，不宣称自动续传。
- **音乐库备份**：“管理 → 存储空间 → 导出音乐库备份”。选择保存目录后生成 `.zuneyra-backup` 文件夹，包含版本清单、音频、可用封面、收藏、歌词、增益标签和歌单。Mac 外部引用在备份中转为音频副本，不导出授权书签。
- **合并恢复**：选择备份文件夹；先检查版本、路径、歌单引用和所有音频 SHA-256，再复制并校验，最后用单个 SQLite 事务合并。任务清单覆盖复制到提交间的崩溃。原音乐库保留；相同哈希音频不重复复制；歌单作为新歌单加入，因此重复恢复会再次创建歌单。播放队列、导入历史和应用偏好不属于可迁移备份内容。
- **M3U8**：管理页可导出所有歌单及相关音频，保持便携相对路径。导入选择包含 M3U/M3U8 的文件夹，只读取该目录内的本地音频，拒绝网络、绝对路径和越界引用。按文件导入，失败音频会报告，已成功导入的歌曲保留；不支持网络播放列表。
- **Mac 引用模式**：“引用音乐文件夹／重新授权”。持久化只读安全作用域书签，读取时恢复访问；重新选择文件夹可扫描新增曲目并更新已有引用的授权。删除曲目只移除库记录及应用封面，不删除外部源文件。普通导入仍默认复制，避免改变已有使用习惯；外部磁盘断开时保留曲目并提示不可用。
- **歌词**：播放器进入歌词页，可导入 UTF-8 LRC／文本；从文件夹导入时读取同名 LRC；支持系统可读取的内嵌歌词和 FLAC LYRICS。多时间标签、毫秒偏移、当前行与点击 seek；歌词随音乐库备份保存。单独选择音频时系统未授予同目录访问权，可能无法自动读取伴随 LRC，此时使用歌词页单独导入。
- **元数据**：补充有界 FLAC Vorbis comment／图片读取、ID3 TXXX 增益字段、碟号读取，以及先碟号后曲号的专辑排序。已有曲目可在“音乐库管理 → 存储空间 → 重新扫描音乐元数据”手动补读；保留收藏、歌单、队列及已有歌词，支持进度、取消和逐曲失败报告。详见 [重新扫描说明](./metadata-rescan.md)。
- **ReplayGain**：关闭／曲目／专辑三种模式，默认关闭，偏好持久化。专辑增益缺失时回退曲目增益，峰值限制放大；通过音频处理 tap 应用正负增益，输出削波保护。渲染回调不访问数据库、不做 I/O、不分配音频缓冲区。实现覆盖本机浮点 32/64 位与整数 16/32 位 PCM；其他渲染格式保持原信号。当前明确验证的标签来源为 FLAC Vorbis comment 与 ID3v2.3/2.4 TXXX，尚未宣称所有容器的增益标签兼容。
- **连续播放**：AVQueuePlayer 预先准备下一首，队列编辑、随机、循环与预加载同步。增加 AVAudioEngine 离线连续调度原型测试。生产后端仍保持单一 AVQueuePlayer，不新增一套并行默认引擎；采样级无缝及编码延迟、跨采样率衔接的录音验证已移至运营阶段按需评估，不作为当前验收门槛。
- **中英文**：字符串目录涵盖管理、播放、歌单、错误、计数与无障碍文案；英文单复数资源及编译产物读取测试。已有歌曲的持久化默认标签不随界面语言改写。
- **隐私清单**：加入无跟踪、无开发者数据采集声明，以及应用偏好和用户授权文件元数据所需 API 使用理由。声明依据当前代码，不代表已通过商店审核。

## 当前范围调整

按 2026-11-05 的产品决定，以下四项已从当前版本需求、开发待办和发布验收门槛中移除，运营过程中再按实际需要考虑，不安排当前排期：

- CarPlay 授权申请与实车测试。
- 长时间播放、续航、耗电和温度验证。
- 最低系统兼容性专项验证。
- 采样级无缝播放的录音与波形边界验证。

既有实现、构建配置和历史证据保留；这些项目的状态为“移出当前范围”，不是“已验收通过”。当前发布范围为 iOS／iPadOS 与原生 macOS，不以 CarPlay 或采样级无缝播放作为功能承诺。工程部署目标仍为 iOS 17／macOS 14，此次不修改部署设置。

详见 [当前版本验收范围调整](./decisions/2026-11-05-release-scope.md)。
