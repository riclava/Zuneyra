# 音乐库管理、存储清理与导入记录

更新：2026-11-04。入口为 iOS 与 macOS 顶部工具栏中的“管理”。

## 多选与删除

点击“选择”，列表切换为歌曲选择模式；可以逐首勾选，或“全选当前结果”。搜索过滤时，已选择的歌曲会保留，选择数量显示的是全部所选项目。点击“删除”会先显示数量、约计音频大小和影响，再确认“删除音频副本”。也可以通过歌曲的上下文菜单删除单首。

删除会移除音乐库记录、收藏标记和应用持有的音频／封面副本。其他原位置文件和 Finder 传入的 Documents 文件不受影响。删除当前播放曲目会停止播放、清除当前播放信息和该条恢复记录，并从队列中移除所有被删曲目。收藏与删除交错执行时，过期的收藏操作不会重新插入已删除的歌曲。未变化的 Finder 传入文件不会因为一次自动扫描就重新加入音乐库；需要时可主动选择原文件重新导入。

删除不可在应用界面撤销。文件先进入私有的删除暂存目录，并写入恢复清单，数据库删除在事务中完成。数据库失败时恢复文件；启动时遇到中断的删除，会根据数据库是否已提交决定恢复或清理暂存文件。删除清单和暂存目录不会暴露到 Finder 文件共享中。

## 存储空间

“管理 → 存储空间”展示音乐副本、电脑传入文件、封面缓存、音乐库与导入记录，以及存在时的任务临时文件。统计为文件逻辑大小的当前快照，文件系统压缩、共享数据块和系统存储统计可能使实际磁盘占用不同；可点“刷新存储占用”重新统计。

“清理已入库的传入文件”仅在存在应用传入目录时显示（正常使用为 iPhone／iPad）。它会重新计算传入文件的 SHA-256，并校验库中音频副本的实际内容，只有完整相同副本仍然存在时才删除传入文件。未入库、已修改、损坏、无法读取以及副本已丢失或损坏的原文件会保留；非音乐文件和符号链接不会被清理。清理结果显示移除数量、文件大小和未处理原因。成功清理后会移除相应扫描标记，之后重新传入同名文件仍可正常识别。

“清理封面缓存”只删除提取的封面文件。音频、收藏和历史保留，再次浏览需要封面的页面时从音频中重建。没有网络抓取。

## 导入记录与重试

“管理 → 导入记录”保留升级后最近 100 次有实际导入操作的批次结果：时间、来源、成功／重复／失败数量和是否取消。关闭导入完成窗口后仍可查看。未发现新文件的自动扫描不会生成空记录。

展开记录可查看失败文件名与错误原因，点击“重试失败文件”再次导入这些来源；每次重试产生一条新记录，原结果作为历史保留。若文件已移动、外置磁盘断开或访问权限失效，请连接磁盘或使用“重新选择来源…”重新授权。外部来源的书签按平台规则尽力保存，不能保证第三方文件提供器永久保留访问权限。

取消导入会保留已成功完成的曲目，并将当前批次记为已停止；尚在检查传输稳定性的 Finder 批次也会记录取消状态。结果记录在批次结束／取消后写入 SQLite；进程在写入结果之前被系统终止的批次，尚不具备完整的中断任务日志和自动续传能力。

数据库、历史中的来源信息和书签保存在私有 Application Support 中，不上传，也不放入 Finder 共享目录。升级前没有被持久化的旧导入结果无法补建。

## 验证

- iOS 模拟器：17 项单元测试、2 项界面回归测试通过。
- macOS：16 项单元测试、2 项界面回归测试通过。
- 覆盖当前歌曲删除、原文件保留、删除事务失败回滚、提交前／后中断恢复、库副本损坏时保留传入源、历史跨启动读取、失败来源重试、封面清理和重建。
- 实际界面验证了多选 → 确认删除 → 查看结果 → 打开存储管理，以及播放中继续搜索。
- 测试删除、清理仅针对隔离临时目录中的合成音频，没有清理用户实际音乐。
