# 使用指南

## 导入音乐

点击「＋」选择音频或文件夹。普通导入会复制到应用私有音乐库，按 SHA-256 内容去重；取消时保留已经成功导入的歌曲。支持扩展名 MP3、M4A、AAC、ALAC、FLAC、WAV、AIF、AIFF，文件仍须通过系统解码验证。

iPhone／iPad 也支持 Finder 文件共享：

1. 安装并打开应用一次，用数据线连接 Mac，解锁并信任设备。
2. 在 Finder 选择设备 → 文件 → Zuneyra，拖入音乐或文件夹并等待传输结束。
3. 回到应用，启动或再次进入前台时自动扫描；也可点「＋ → 导入电脑传入的音乐」。

自动扫描忽略隐藏文件、符号链接和非音乐文件。未变化且已处理的文件不会重复提示；失败文件会在后续扫描中重试。Finder 展示的是 Documents 中的传入原文件，播放使用 Application Support 中的副本，两份都保留并占用空间。删除其中一份不会同步删除另一份。Finder 未显示应用时，可打开应用后重新连接设备。

Mac 可用「引用音乐文件夹／重新授权」直接读取外部音频，不复制入库。重新选择文件夹可发现新增歌曲并刷新授权；外置磁盘断开时保留曲目并提示不可用。普通导入仍默认复制。

「管理 → 导入记录」保留最近 100 次有实际导入操作的批次结果，可查看失败原因、重试失败文件或重新选择来源。中断的未完成文件需重新导入，不支持自动续传。

## 歌单与播放队列

在「歌单」中创建、重命名或删除歌单。名称去除首尾空白后为 1–100 个字符，不接受控制字符；允许同名歌单。歌曲菜单、多选、专辑菜单和歌单详情加号均可添加歌曲。单张歌单不重复添加同一歌曲；支持拖动、上移／下移和移除。iOS 从「歌单操作 → 调整顺序」进入排序。移除成员或删除歌单不删除音频。

「播放全部」按歌单顺序建立队列并关闭随机；「随机播放」随机安排首曲及其余曲目。点单曲从该曲开始播放，保留循环偏好。建立队列后再编辑或删除歌单，不改变已有队列。

歌曲菜单的「下一首播放」「稍后播放」可插入或追加队列，不打断播放，也不自动启动空队列。同一歌曲可以多次加入队列，每个条目独立。待播条目可拖动排序（iOS：队列操作 → 调整顺序），也可上移、下移或移出；清空待播保留当前和已播放条目，移除当前条目会停止播放。

随机只调整待播部分；关闭随机后回到基准相对顺序，手动排序成为新基准。上一首沿实际播放顺序回退，进度超过 3 秒时先回到当前曲目开头。单曲循环作用于自然结束，手动下一首仍切歌；列表循环从头开始新一轮；关闭循环时末曲结束后停止。

队列、模式和进度会保存，重启恢复为暂停。播放中约每 5 秒保存进度，意外退出可能丢失最近检查点后的进度。丢失文件的直接选择会报错，下一首会有界跳过，全部不可用时停止；系统解码失败会报错停止。

播放器主页采用固定布局，封面随剩余高度缩放。进度条紧邻底部播放控制上方；底部依次是播放模式、上一首、播放／暂停、下一首和队列。播放模式只显示图标，点击依次切换顺序播放、列表循环、单曲循环、随机播放。点击专辑封面可在原区域显示歌词，下方歌曲信息、进度和播放控制保持固定；辅助操作栏以图标依次提供歌曲信息、添加到歌单、音频输出、音量均衡设置和收藏；歌曲信息面板显示歌名、歌手、专辑、时长与文件格式。「添加到歌单」可选择已有歌单或新建歌单，操作绑定打开时的歌曲，不受期间切歌影响。点设置图标，可在弹出的音量均衡面板中选择 ReplayGain「关闭／曲目／专辑」模式。iOS 从左边缘向右滑可关闭播放器；在队列子页执行相同手势会先返回上一页。歌词模式仍属于播放器主页，左边缘右滑直接关闭播放器。

iPhone／iPad 音乐库主页支持在内容区域左右滑动切换分类：左滑依次进入专辑、歌曲、艺术家、收藏、歌单中的下一项，右滑返回上一项，两端不循环。手势识别为横向后锁住纵向滚动，松手或取消后恢复；纵向手势不切换分类。拖动时当前分类与相邻分类的真实内容同步跟随手指横向移动，相邻页面填满露出的区域，未选中页面不响应操作；松手后距离足够则切换，距离不足则回弹；切换时内容沿对应方向滑出／滑入，顶部导航和底部迷你播放器保持固定；开启系统「减少动态效果」时立即切换。边缘滑动仍用于历史返回／前进；专辑或歌单详情内、批量选择期间不切换分类。

## 歌词与音量

播放器歌词模式可导入 UTF-8 LRC／文本（不超过 1 MB），支持时间标签、偏移和当前行高亮。点击封面进入歌词模式，点击歌词文字或区域空白处即可切回封面，也可使用右上角的封面图标；按钮操作与滚动不会切换模式。只有区域内歌词可以滚动，整页不滚动。iPad 宽屏采用同样的封面／歌词切换，右侧专门显示播放队列。手动翻阅暂停自动跟随，点击「回到当前句」恢复。点击歌词右侧的播放图标选中该句，再点击「从这里播放」跳转。已有歌词时从顶部更多菜单导入；导入始终绑定打开文件选择器时的歌曲，不随期间切歌而改变。文件夹导入可读取同名 LRC，也支持可读取的内嵌歌词。单独选择音频时系统可能未授权访问旁边的 LRC，可在歌词模式中单独导入。

ReplayGain 默认关闭，可选曲目或专辑模式；专辑增益缺失时回退曲目增益，并使用峰值限制放大。当前明确验证的标签来源为 FLAC Vorbis comment 和 ID3v2.3/2.4 TXXX，不承诺所有格式的增益标签兼容。

## 旧音乐库重新扫描元数据

进入「音乐库管理 → 存储空间 → 重新扫描音乐元数据」。可查看进度、取消，以及结束后的更新／跳过／失败明细。扫描期间阻止另一项导入、删除或库管理任务，播放控制仍可使用。

扫描当前托管副本或 Mac 已授权引用，补读曲名、艺术家、专辑、专辑艺术家、曲号、碟号、时长、封面、歌词和 ReplayGain。只有成功读取的字段覆盖旧值，缺失字段保留；已有非空歌词始终保留，需要替换时在歌词模式中重新导入。可访问的同名 LRC 可补充缺失歌词，复制入库后不重新寻找原导入目录。

歌曲身份、音频、收藏、歌单、队列顺序和来源授权保持不变。结束后刷新当前歌曲、锁屏信息及增益，保持暂停状态和播放位置。每首单独保存，取消或退出保留已完成更新。

缺失、无权限、损坏或扫描时变化的音频逐曲报告失败，其他曲目继续。文件内容必须与入库时的 SHA-256 一致；若在外部编辑过音频或标签，请重新导入该文件，重扫不会把变化后的文件关联到旧歌曲身份。

## 备份与迁移

「管理 → 存储空间 → 导出音乐库备份」生成 `.zuneyra-backup` 文件夹，包含 `manifest.json`、音频、可用封面、收藏、歌词、增益标签和歌单。Mac 引用转换为音频副本，不导出授权书签。队列、导入历史和应用偏好不包含在备份中。

恢复时选择完整备份文件夹。应用先验证版本、路径、歌单引用和全部音频哈希，再合并到现有音乐库；同内容歌曲去重并保留已有记录，歌单作为新歌单加入。重复恢复会再次创建歌单。损坏备份不会覆盖现有库。

管理页也可导出所有歌单及相关音频为 M3U8。导入时选择包含 UTF-8 M3U／M3U8 和音频的文件夹，只接受目录内的相对路径，不支持网络、绝对路径或越界引用。逐文件报告失败，保留成功导入的歌曲。当前不提供跨设备自动同步。

## 删除与清理

从歌曲菜单或列表「… → 选择歌曲」进入删除／多选操作。删除音乐库歌曲会清除收藏、歌单和队列引用，以及应用拥有的音频／封面副本；删除当前歌曲会停止播放。Mac 外部源文件和 Finder 传入原文件保留。删除操作需确认，应用界面没有撤销入口；未变化的 Finder 文件不会因下次自动扫描重新入库，需要时主动导入原文件。

「管理 → 存储空间」可刷新占用快照。显示的是逻辑文件大小，可能与系统磁盘统计不同。

- 清理已入库的传入文件：只删除与完整托管副本重新校验后一致的传入文件。未入库、修改、损坏、无权限或托管副本丢失的原文件保留。
- 清理封面缓存：只删除提取图片，音频和收藏保留，后续从音频重建封面；不会联网抓取。

卸载应用可能删除私有音乐库，迁移或卸载前先导出备份。

## 管理页面

「存储空间」先显示本机占用总量与分类明细，右上角按钮可刷新统计。「空间清理」集中提供传入文件与封面缓存清理，执行前仍需确认；传入文件总大小不代表全部可清理大小，实际删除仍以内容核对结果为准。「备份与迁移」「音乐库维护」默认折叠，展开后进行备份、M3U8 迁移、标签重扫及 Mac 文件夹引用授权。

「导入记录」统计最近保留的至多 100 批结果，可筛选全部、有失败、已停止。每张卡片显示来源、时间、状态和数量；成功记录无需展开，有失败时展开详情查看原因并重试。旧记录若只有错误文字而没有文件引用，可重新选择来源；停止的批次可能已成功导入部分歌曲，也可能同时包含失败。
