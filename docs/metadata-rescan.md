# 旧音乐库重新扫描元数据

更新：2026-11-05。

## 使用

打开“音乐库管理 → 存储空间 → 重新扫描音乐元数据”。扫描显示已检查数和总数，可以取消；已完成的单曲更新会保留。完成后显示更新、跳过、失败数量及失败明细。扫描期间阻止另一项导入、删除或库管理任务，播放控制仍可使用。

## 更新规则

导入和重新扫描共用标签解析逻辑。扫描从当前托管音频副本或 Mac 已授权引用读取曲名、艺术家、专辑、专辑艺术家、曲号、碟号、时长、封面、内嵌歌词和 ReplayGain。可访问的同名 LRC 也可补充缺失歌词；复制入库后不重新寻找原导入目录里的伴随文件。

- 只有成功读取的字段覆盖旧值；缺失的标签保留旧值。
- 已有非空歌词始终保留，包括手动导入的歌词。需要替换时可在歌词页重新导入。
- ReplayGain 各字段分别补读，源文件缺少的字段保留旧值。
- 歌曲 ID、文件名、内容哈希、收藏和来源书签保留；不重建曲目，不修改音频，不改变歌单成员及播放队列顺序。
- 封面使用内容哈希命名缓存，读取到新封面后刷新视图；旧缓存可通过现有清理入口移除。
- 当前歌曲的显示、锁屏媒体信息和增益设置在扫描结束后刷新，暂停状态及播放位置保持。

## 失败与并发

先核对音频哈希，再读取元数据并检查文件大小和修改时间。来源缺失、权限不可用、损坏、内容与入库时不同、扫描期间发生变化时，保留原记录并报告该曲失败，继续其余曲目。源文件内容已变化时，请重新导入来源文件；本功能不把内容变化偷偷关联到原有歌曲身份。

每首完成后单独保存，取消或进程退出不会撤销已完成更新。解析期间允许 actor 接收其他调用；落库前重新读取最新记录并合并收藏与歌词，不复活已删除歌曲、不覆盖最新来源授权。

## 覆盖测试

- 不含新增字段的旧 JSON 记录补读 FLAC 标签、碟号、内嵌歌词、ReplayGain，保留文件、收藏和歌单，重启后持久化。
- 重复扫描不产生无意义更新；缺失标签不清空旧值。
- 封面恢复、歌词保留及缺失歌词补充。
- 缺失／变化音频失败隔离；中途取消保留已完成部分。
- 快照创建后的删除、收藏及歌词修改得到保留。
- PlayerStore 刷新当前歌曲但保留暂停位置、队列身份和顺序。
- Mac 引用书签及源文件保持不变。
