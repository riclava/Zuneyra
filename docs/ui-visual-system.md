# 私人唱片收藏室：界面视觉约定

更新日期：2026-11-04。当前方向为「私人唱片收藏室」：奶油白与深酒红、覆盆子红强调、编辑式排版和较大的专辑封面。界面颜色与实际 App icon 呼应，保留现有收藏室布局；布局与交互结果由实际运行画面单独确认。

## 颜色与材料

颜色集中在 `Zuneyra/SunsetTheme.swift`。实际 iOS 1024 图标与 Mac 512 图标均使用覆盆子红至玫红底色、奶油色音符；采样得到的代表色包括 `#DA0349` 与 `#FDF5DE`。界面采用稳定的纯色，纸张、封套和播放栏分别使用奶油色、浅玫瑰色与深酒红。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 `background` | `#FFFAF0` | `#1D141B` |
| 次级区域 `panel` | `#F7EFDF` | `#281B24` |
| 封套与输入区 `elevated` | `#FFFDF6` | `#33212C` |
| 文字与图标强调 `accent` | `#BF003C` | `#FF7C9F` |
| 次要文字 `secondary` | `#705B63` | `#C7ADB7` |
| 边界 `stroke` | `#DFD1CC` | 奶油色，14% 不透明度 |

`Sunset.brand` 为 `#D50043`，主按钮配 `Sunset.paper`（`#FFF9DF`）奶油色文字。`Sunset.ink` 为 `#281A21`，用于迷你播放器背景。浅色文字强调比按钮红更深，保证选中底上的文字可读性；`AccentColor` 资产与浅色／深色 `accent` 同步。选中、播放与收藏状态同时保留图标、文字或辅助功能值。

## 页面构成

- 页面与专辑标题使用系统衬线设计，说明、歌曲元信息与操作使用系统常规字体。计数、序号和时长保留等宽数字。主内容水平边距为 24 点，最大宽度为 1100 点。
- 专辑首页先展示馆藏标题，再显示 `CollectionFeatureView`，最后进入「全部专辑」网格。展示区使用真实专辑：有当前曲目时显示其专辑，否则显示专辑列表首项；提供继续聆听／播放专辑与查看专辑两个动作。
- 展示区宽布局为文字与 208 点封套并排；空间不足时改用紧凑封面组合，辅助功能字号使用纵向排布。封套轻微旋转与阴影只用于视觉，不改变内容语义。
- 专辑网格在 Mac 使用 190–300 点自适应封面，手机使用 145–280 点；辅助功能字号增大最小列宽。封面下依次显示专辑名、艺术家与歌曲数量，避免每张专辑再套完整卡片。
- 专辑详情宽布局使用 220 点封面，窄布局将 200 点封面放到介绍上方。播放动作进入专辑介绍区，下面接曲目目录。Mac 全库列表保留专辑列，专辑详情省去重复专辑列；音乐库歌曲行封面为 44 点。
- 歌单使用封套式拼图封面与私人选集标题。队列、导入记录和管理页沿用纸色背景、分组留白与较弱分隔线。

## 共用组件

- `CoverArt` 优先显示真实封面。缺失封面时按专辑名稳定选色，生成黑胶、专辑名和艺术家组成的占位封套；小尺寸省略封套文字。长专辑名的可读性也属于封面验收范围。
- `CollectionSheetHeader` 将标题、返回与关闭按钮放在同一纸色内容面上。静态弹窗不使用 NavigationStack；播放器与队列保留导航栈，但隐藏系统标题和底部工具栏，避免出现独立白色栏。关闭／返回支持 Esc，表单保存／添加保留默认操作快捷键。
- `StudioMark` 使用同心圆唱片标记。`StudioEmptyState` 统一圆形图标底、衬线标题与说明；导入、清除搜索、添加歌曲等下一步操作由页面提供。
- `StudioButtonStyle` 使用 9 点圆角，区分主要与次要动作，并保留按下与禁用反馈。`StudioIconButtonStyle` 统一工具栏操作区域。
- 迷你播放器为墨色播放台，使用 50 点封面、圆形播放按钮和细进度线；Mac 另有可调整时间轴与队列入口。完整播放器使用较大封面、衬线曲名和圆形主播放按钮，封面随可用高度调整。
- 原生列表移动、删除、系统文件选择、音频输出和确认弹窗继续承担对应交互。队列和歌单样式调整不改变数据与播放语义。

## 平台与无障碍

- macOS 使用 210 点侧栏，窗口最小为 800×580 点。侧栏条目高 43 点，普通按钮最小高 36 点；切换分类会返回分类根页面。歌曲列表表头与行保持列对齐，选择模式保留尾部操作占位。
- iOS 使用顶部品牌与工具动作、搜索及横向文字分类。主要触控按钮、歌曲操作和排序入口保持至少 44 点的操作尺寸；歌单详情使用内容内返回入口。
- iOS 歌曲、艺术家和收藏页的大标题只承载标题及数量。批量选择收进列表操作区的「…」菜单，菜单项为「选择歌曲」；歌曲和收藏页同时提供排序，艺术家目录行提供同款入口。空收藏、搜索无结果和选择模式不展示该菜单。
- 语义字号增大时，相关操作组改为纵向，迷你播放器减少次要控件，完整播放器缩小封面。长标题允许换行；装饰图形不参与重复朗读。
- 图标按钮保留名称，播放、收藏、选择和循环状态保留辅助功能值。进度条可通过辅助功能操作每次前进或后退 10 秒。
- 队列、管理弹窗的根容器与空态填满可用空间，播放器空态使用当前内容区高度；不得重新引入标题下移或内容越界。

## 界面手动验收

检查浅色与深色、窄屏与缩小后的 Mac 窗口、长专辑名／曲名和辅助功能字号。重点查看展示区与专辑详情的横纵布局切换、缺封面文字可读性、主要播放动作是否可达，以及空音乐库、空歌单、搜索无结果、队列清空后的容器边界。确认关闭、返回、侧栏切换和选择模式仍可正常使用。
