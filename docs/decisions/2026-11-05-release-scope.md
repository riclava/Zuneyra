# 当前版本验收范围调整

日期：2026-11-05（Asia/Singapore）。状态：已采纳。

## 决定

根据用户明确要求，从当前版本需求、开发待办、里程碑退出条件和发布门槛中移除：

1. CarPlay 授权申请与实车测试。
2. 长时间播放、续航、耗电和温度验证。
3. 最低系统兼容性专项验证。
4. 采样级无缝播放的录音及波形边界验证。

上述事项仅作为运营阶段候选，届时依据用户反馈、设备分布和运营需要决定是否启动；当前不排期、不要求补测、不作为开发未完成的依据。

## 影响

- 当前发布范围为 iOS／iPadOS 与原生 macOS；不承诺 CarPlay 或采样级无缝播放能力。
- 保留已有 CarPlay 实现、专用 scheme、连续播放预加载、音频实验及历史证据。现有自动回归仍可运行，不需新增上述专项验收。
- 工程部署目标 iOS 17／macOS 14 保持不变；移除的是最低系统专项验收，不是自动提升最低部署版本。
- 此决定不将未执行的验证改写为已通过，也不改变既有测试结果。
- 其他已列出的功能验收、账号资料、签名和商店提交事项保持原范围。

## 方案与取舍

选择从当前范围移除，而非继续作为发布阻塞项。这样当前交付不再等待这些专项验证与外部权限；相关能力的进一步投入及验证在运营阶段重新决策。无数据模型、迁移或运行时代码变更。
