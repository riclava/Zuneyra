# Zuneyra

适用于 iPhone、iPad 和 Mac 的本地音乐播放器，使用 SwiftUI 构建。导入自己的音乐，按专辑、艺术家或歌曲浏览，管理收藏、歌单、歌词和播放队列；支持音乐库备份、M3U8 迁移及 Mac 文件夹引用。无需账号或音乐服务订阅。

## 开始使用

用 Xcode 打开 `Zuneyra.xcodeproj`，选择 `Zuneyra` scheme 和 Mac 或 iOS 模拟器运行。真机运行需要配置开发签名。工程部署目标为 iOS 17／macOS 14；最近验证使用 Xcode 26.6，部署目标不代表已完成最低系统专项验收。
